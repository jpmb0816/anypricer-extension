# What's new

## 1.0.10 - 2026-11-23
- Cleans up old saved data on each computer automatically: only what the current script versions use is kept (nothing is deleted online)
- Saved data of scripts removed for 7 days is cleaned up
- Admin can clear one script's saved data on every computer once (the online copy is downloaded again)

## 1.0.9 - 2026-11-23
- Online sync: saves from every computer now reach the database, even when its clock is off
- Scripts can upload now and check the online copy (Save online now)
- Online database size in the popup and Settings
- Items over 2 MB stay on that computer (Settings shows them) instead of blocking uploads
- Fixed: the first upload on a newly connected computer could fail
- Admin tools appear only on the admin computer

## 1.0.8 - 2026-11-23
- Quick update: a ↻ button per script, and "update all" on each library heading (popup and dashboard)
- Scripts can keep data on this computer only (not uploaded), show online sync status and upload now
- Scripts can start turned off on first install
- Faster saving for scripts that store many records

## 1.0.7 - 2026-11-22
- Test update: the ⓘ icon at the top of the popup shows who developed it and when this version was released
- The setup file name now has the version in it (ScriptInjector-Setup-1.0.7.exe)

## 1.0.6 - 2026-11-22
- Popup update banner: "Download update" gets the setup (it updates this copy in place), "Apply now" once the new version is downloaded, and "Skip this version" to stay on yours
- Setup: a new team code replaces the old team settings; leave it empty to keep the current team code
