    URL patterns

    Each line in Include / Exclude is one pattern. A script runs when any include matches and no exclude matches. Matching happens inside the page on every load, so changes apply immediately.

    FormExampleMeaning
    All* or <all_urls>Every http(s), file and ftp page
    Match pattern*://*.example.com/app/*Chrome match pattern. *. in host includes the bare domain. Hash is ignored.
    Regex/^https:\/\/(www\.)?site\.com\/(a|b)\//iWrapped in slashes, optional flags. Tested against the full URL including #hash.
    Globhttps://site.com/*?id=** = any characters, ? = one character. Whole URL must match.

    Inside your script

    • With Wrap in async function on (default) you can use top-level await and return, and errors are reported with the right line numbers.
    • injector is available: injector.name, injector.trigger (auto · spa · reinject · manual), injector.log(...), injector.report(error).
    • Turn wrapping off if you need var/function declarations to become page globals (MAIN world).
    • Page (MAIN) world shares window with the page. Isolated world shares the DOM only and is invisible to page scripts.
    • Reinjecting runs the script again, so make scripts idempotent if you reinject often, for example by checking if (document.getElementById('my-el')) return;.

    Error reporting

    Errors thrown synchronously, in awaited code, in uncaught callbacks and in unhandled promise rejections are captured, together with injection failures such as CSP blocks or registration errors. They appear in the popup, the toolbar badge (red count) and the Logs tab.

    Engines

    User Scripts engine: uses Chrome's chrome.userScripts API. It bypasses page Content-Security-Policy and runs at exact timing. Requires Allow User Scripts (Chrome 138+) or Developer mode (Chrome 120–137) on chrome://extensions.

    Limited mode: falls back to inserting a <script> tag. It works on most sites, but strict-CSP pages block it and the failure is reported. Scripts always run in the Page world.

    Shortcuts

    • Alt+Shift+S open popup
    • Alt+Shift+T turn injection on/off
    • Alt+Shift+R reinject into current tab
    • Right-click any page → Script Injector for reinject, pause site, and run any script.

    Install scripts

    1. Copy the link your admin gave you (a script, an index.json or a GitHub folder) and paste it in the box below.
    2. Private library? Ask your admin for its access token and paste it in the Access token box. It is saved for that library only and used automatically for its updates (see Settings → Private repo tokens). Public links need no token.
    3. Click Load, tick the scripts you want, then Install.

    Paste one link per line: a .js script, an index.json that lists several, or a GitHub folder (github.com/owner/repo/tree/main/folder: every .js in it). Scripts already installed (same @id) are updated.
